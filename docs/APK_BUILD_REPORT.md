## Результат

Отдельный Cloudflare Worker опубликован с постоянной D1. Имя больше не
определяет аккаунт: у устройства индивидуальная сессия, D1 хранит SHA-256
ключа. Тестовые заголовки и заголовки идентичности Sites на публичном API
игнорируются. Выход отзывает сессию и очищает интерфейс перезагрузкой.
Новый гостевой старт создаёт новый профиль; восстановления на другом
устройстве в этой версии нет.

APK содержит новый адрес по умолчанию. Прежние сохранённые адреса AI Studio
этого проекта заменяются однократно; произвольные адреса сохраняются.
Повторный вход после перезапуска проверен отдельно. Старый APK 2.5.1
не поддерживает авторизацию нового API, поэтому нужно обновиться.

## Проверено

- 148 автоматических тестов, 0 ошибок.
- 27 браузерных сценариев: MVP 7, минутные режимы 8, настоящая модель/WASM 2,
  запуск без сервера / нативная маршрутизация 5, новый защищённый API 5.
- Новый интерфейс: два одинаковых имени принадлежат разным профилям,
  сохранение повторения владельцу, сохранение сессии после перезапуска,
  дуэль между браузером и APK, выход и новый чистый профиль.
- Нативный HTTP в браузерных проверках имитируется; API, SQLite и UI настоящие.
- Wrangler dry-run настоящего Worker: D1, статические ресурсы, run_worker_first,
  ограничение частоты регистрации; все 4 миграции на настоящем локальном D1.
- Проверка API на настоящем локальном Workers/D1 runtime: health, JSON,
  регистрация, чтение состояния и отзыв сессии.
- Реальная облачная публикация и проверка через GitHub Actions:
  https://github.com/rojoscarlos-cpu/Test/actions/runs/39766244851.
  D1 создана, миграции применены, версия/JSON/сессия/чтение/выход проверены.
  Проверка не создаёт демонстрационных профилей и повторений в рейтингах.
- Gradle clean assembleDebug, подпись, совпадение сертификатов, CRC,
  versionCode 20502, фактический адрес и Bearer-авторизация в ресурсах APK,
  наличие модели/WASM/Worker и разрешений CAMERA/INTERNET/WAKE_LOCK.

Физический Samsung Galaxy S23 не подключён к среде сборки: разрешение камеры,
реальные движения, звук и сетевой доступ с телефона проверяются на устройстве.
Google AI Studio и прежний приватный Sites не перепубликовывались; старые
данные автоматически не переносились. В Cloudflare отдельная постоянная база.

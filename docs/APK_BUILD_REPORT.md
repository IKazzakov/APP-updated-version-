## Проверено

- Чистая установка зависимостей `npm ci` по восстановленному lockfile.
- 132 автоматических теста: 0 ошибок, включая нативный HTTP и гонки удержания экрана.
- Сборка клиента, Worker и Android Java-кода; Gradle `:app:clean assembleDebug`.
- 17 браузерных сценариев: MVP — 7, автоматический старт — 8, настоящая Pose Full/WASM и восстановление после HTTP 503 — 2. Ошибок JavaScript нет.
- Подпись APK, целостность ZIP/CRC, версия и пакет.
- Разрешения INTERNET, CAMERA, WAKE_LOCK; вертикальная ориентация; cleartext отключён.
- Pose Full, WASM и Worker присутствуют внутри APK; нативный WorkoutScreen включён в DEX.
- APK не содержит предыдущий APK или старый ZIP экспорта исходников AI Studio.
- Повторный `npm run cap:sync` исключает APK из `dist/android-client` и нативных ресурсов, сохраняя скачиваемый APK в веб-каталоге.

Первый дополнительный браузерный прогон завершился таймаутом во время
проверок установки зависимостей. После чистой установки все сценарии
повторены последовательно и прошли. Причина первого таймаута не доказана.

## Исправления

- Переносимый скрипт сборки вместо путей `/app/applet` и записи в `/opt`.
- JDK 21 и SDK 36 проверяются перед сборкой; версия Android берётся из package.json.
- Android-ресурсы готовятся отдельно от веб-каталога скачивания APK.
- Запросы из APK идут через CapacitorHttp с нужным Origin и cookie-хранилищем Android.
- Ссылки приглашений используют публичный адрес вместо localhost; отключён Service Worker внутри APK.
- Добавлено нативное удержание экрана и исправлено его преждевременное освобождение во время подготовки.
- Из Git удалены машинные пути, Gradle-кэши и генерируемые файлы Android.

## Пределы проверки

APK не устанавливался на физический Samsung Galaxy S23; реальные движения,
разрешение камеры и слышимость сигналов проверяются на телефоне.
Браузерные сценарии выполнялись на отдельной тестовой базе, не на сервере
пользователя. Серверный адрес сохранён из проекта; доступ к нему из среды
сборки ограничен сетевым прокси, поэтому живую синхронизацию с ним здесь
подтвердить нельзя. Подготовка APK не публикует и не изменяет этот сервер.

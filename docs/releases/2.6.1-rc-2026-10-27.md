## Что ещё не выполнено

Backend реализовал GET-only checker и серверные регрессии, но не подтвердил
фактическую версию опубликованного Worker, защищённые маршруты и remote 0005:
нет подключённой профильной сессии/Cloudflare read-only доступа, endpoint недоступен
из рабочей среды. Старый Worker остаётся гипотезой. Общие исходники API и миграция
есть в кандидате; сам факт сборки не доказывает их публикации.

**NOT_RUN:** установка APK, сохранность реальных данных телефона, реальные движения,
звук/FPS/нагрев, фактическая доставка зависшей записи, authenticated live checker,
read-only проверка remote схемы/версии. Все исходные телефонные пункты остаются
непроверенными, пока владелец не сообщит результат.

## Следующие действия владельца и команды

1. Можно установить этот APK поверх 2.6.0, без удаления приложения/очистки данных.
   При предложении удалить прежнее приложение остановиться.
2. Скопировать диагностику: версия 2.6.1, versionCode 20601, полный source SHA выше,
   dirty=false и фактический API-base должны появиться автоматически.
3. Открыть прежнюю программу/сохранение и нажать «Проверить снова».
   При отсутствующих маршрутах UI должен назвать несовместимость, сохранить работу
   и не создавать бесконечные POST. Это допустимая короткая проверка исправления.
4. После подтверждения совместимого API прежние UUID → ack очереди → сохранённый
   pendingEnd → подтверждённый aborted; затем другая программа без reload/двойного XP.
   Только после этого продолжать полный [чек-лист](../PHONE_ACCEPTANCE.md).

Если API несовместим, не пытаться обойти блокировку очисткой профиля/IndexedDB,
сменой API или переустановкой. Нужен согласованный выпуск API/0005.
Запрос подготовить APK не разрешает merge main, remote-миграцию или публикацию:
они в этой задаче не выполнялись. Функциональный следующий этап пока отложен.

## MOV-RC-BUILD-02 — Frontend: APK общего SHA

**Цель:** получить подписанный APK общего Backend + Frontend + документов.
**База:** точный интеграционный SHA из PR/сообщения Тимлида; рабочая ветка
codex/rc-integration-20261027. Не использовать вместо него 053595d или cec8fb1.

**Владелец:** Frontend / исполнитель Android-сборки. **Границы:** штатный запуск
Movement — checks and APK (backend.yml) на указанной ветке с build_apk=true;
артефакты Actions и собственный текстовый отчёт. Продуктовые файлы, номер версии,
workflows и общие типы/валидаторы не менять. Их владелец остаётся Тимлид.

**Вход:** прочитанные актуальные AGENTS/TEAM_CONTEXT/HANDOFF, полный MOV-RC-01,
точный source SHA, прежний Actions signing secret. **Выход:** run URL/ID и
artifact URL/ID/name, actual source SHA, expires_at, APK/JSON/SHA-256/manifest,
2.6.0/20600 и прежние package/API/certificate. Повторная сборка может иметь другой hash.
API/auth/ошибки/идемпотентность/пагинация/ревизии не меняются; схема остаётся 0005.

**Проверки:** run checkout/head соответствует заданному SHA; checks и Android job
success; подпись, manifest, байты и суммы согласованы. При ошибке не подменять
артефакт старым FE APK. Не выдавать доступность файла за физическую приёмку.

**Зависимость и порядок:** запуск после фиксации общей ветки Тимлидом. Если её head
изменился, получить актуальный source SHA из обновлённой передачи; самовольно не
переписывать branch. Тимлид проверяет артефакт и комплект совместимого Worker/статики.
Ссылка на отчёт может быть коммитом позже source SHA, сборочный SHA при этом сохраняется.
У текущего GitHub-коннектора Тимлида есть чтение/скачивание artifacts, но нет метода
workflow_dispatch; отправка нового build требует инструмента с Actions dispatch
либо штатного ручного запуска GitHub UI. Это ограничение инструмента, не запрос
нового разрешения на уже согласованную подготовку APK.

**Граница разрешения:** только сборка и передача артефакта. Main не сливать,
deploy.yml/backend:deploy не запускать, remote-миграции и установку на телефон
не выполнять. Полный цикл на телефоне требует отдельно разрешённого совместимого
API; старый опубликованный Worker новых маршрутов не поддерживает.

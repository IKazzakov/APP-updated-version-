# Установка и сборка Android 2.5.4

Текущий APK — **Движение Тест UI**, `com.movement.squat.staging.ui`, версия 2.5.4 / 20504, Android 7.0+ (API 24), compile/target SDK 36. Это подписанный debug APK для прямой установки, не пакет Google Play.

Основной репозиторий — `APP-updated-version-`, ветка `main`. Имя Android-пакета и постоянный ключ сохраняются ради обновления уже установленного приложения и сохранения профилей.

## Установка

1. Скачать `public/app-debug.apk` либо новый artifact `movement-android-<commit>` из GitHub Actions.
2. Открыть APK на телефоне и разрешить установку из выбранного источника. Установить поверх существующего **Движение Тест UI**.
3. На первом запуске нажать **Быстрый старт (Гость)** или ввести имя. `401 DEVICE_AUTH_REQUIRED` до входа ожидаем.
4. Открыть **Тренировка → Начать** и разрешить камеру. Микрофон не нужен.
5. Дождаться подтверждения сохранения. Не выходить из профиля и не очищать данные ради обновления.

При несовпадении подписи остановить установку и проверить сертификат APK: правильное обновление не требует удаления установленного приложения. Закреплённый отпечаток указан в [ANDROID_SIGNING.md](ANDROID_SIGNING.md).

## Проверка на Galaxy S23

- Сохранение прежнего профиля после обновления и перезапуска.
- Первый вход нового устройства, запрос разрешения камеры и отказ с понятной инструкцией.
- Подсчёт 10 полных приседаний при видимых тазе, коленях и стопах, без горизонтальной прокрутки.
- Подготовка, 5–4–3–2–1, звуковые сигналы, полная минута и минутный рекорд.
- Вызов у двух участников: ранняя остановка учитывает подтверждённые повторения; лучшая из трёх попыток, без минутного рекорда для `aborted`.
- Уход в фон, потеря сети, повторная отправка и очередь без дублей после перезапуска.
- Общая диагностика на всех экранах; отчёт без имён, токенов и координат.

Единственный основной API — `https://movement-test-api-staging.rojoscarlos93.workers.dev/api`. Техническое имя сохранено ради профилей и очередей. Настройка подключения находится внутри диагностики. [Объединение серверов](SINGLE_SERVER.md).

## Повторная сборка

Нужны Node.js 24+, полный JDK 21 (`javac`), SDK Platform 36, Build Tools 36.0.0, platform-tools, принятые лицензии SDK и прежний закрытый ключ.

```sh
npm ci
source scripts/android-env.sh
javac -version
sdkmanager --list_installed
npm run build:apk
```

Пути можно задать через `JAVA_HOME`, `ANDROID_HOME` и `MOVEMENT_STAGING_KEYSTORE`. По умолчанию локальные инструменты находятся в `work/android-env`, ключ — `work/signing/staging-debug.keystore`. [Подготовка среды и CI](DEVELOPMENT.md), [восстановление ключа](ANDROID_SIGNING.md).

Результат: `work/artifacts/app-debug.apk`, SHA-256, JSON и открытый manifest. Версия вычисляется из `package.json`; для будущего обновления повышается versionCode при сохранении пакета/ключа. Базовая конфигурация и совместимая команда `build:apk:staging` используют тот же установленный пакет и закреплённый ключ.

Проверка подписи и содержимого не измеряет точность распознавания, частоту кадров или нагрев S23. Эти проверки выполняются на физическом устройстве.

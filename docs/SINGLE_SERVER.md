# Один основной сервер · 2.5.4

Основная ветка — main репозитория APP-updated-version-. Весь принятый код и история выпуска объединяются в неё; поглощённые временные ветки удаляются после проверки достижимости их коммитов из main.

## Основная инфраструктура

- API и приложение: `https://movement-test-api-staging.rojoscarlos93.workers.dev`.
- Worker: `movement-test-api-staging`.
- Единственная рабочая D1: `movement-test-app-staging`.
- Планировщик обслуживания: Cron этого же Worker.
- Android: `com.movement.squat.staging.ui`, прежний сертификат и прежнее имя signing secret.

`staging` осталось в технических именах. Отдельного тестового backend в рабочем процессе нет. Все актуальные команды и конфигурация указывают на одну инфраструктуру. Деплой выбирает только существующую основную D1 и останавливается при её отсутствии; пустая замена автоматически не создаётся.

## Почему адрес сохранён

Device-secret хранится по адресу API, а Outbox и восстановление раунда — по адресу и профилю. Смена URL создала бы другой раздел локального хранилища. Версия 2.5.4 сохраняет действующий URL, пакет и ключ: текущие профили, очередь с устойчивыми UUID и незавершённое подтверждение не требуют переноса на телефонах.

Базовая конфигурация Capacitor и обычный build:apk теперь соответствуют установленному пакету. Сохранённые пользовательские адреса не переписываются молча; диагностика остаётся доступной для настройки подключения. Для штатного приложения используется только основной адрес выше.

## Данные бывшего второго сервера

Проверка 23 октября 2026 года показала:

- В основной базе: 5 профилей, 65 событий повторений, 3 раунда и 2 соревнования.
- В прежней movement-test-app: один профиль и 3 записи сессий, без повторений, прогресса, наград, раундов и соревнований.

Для этого конкретного случая выполнен ограниченный перенос только профиля и сессий: 1 профиль и 3 сессии добавлены в основную базу. Перенос требует отсутствия спортивных данных в источнике, проверяет конфликты идентификаторов/хешей и одинаковость уже перенесённых записей. Существующие профили и история основной базы не переписывались. Агрегаты нового профиля создали штатные SQL-триггеры; глобальные недели и начисления не копировались.

До записи фиксируются Time Travel bookmarks обеих баз. Источник сохраняется неизменным. Результаты содержат агрегированные числа без имён, пользовательских ID или хешей сессий. Повторный запуск безопасен; при появлении тренировочных данных в старой базе перенос останавливается вместо слепого объединения таблиц.

Прежний Worker movement-test-api удалён после успешного основного деплоя, проверки сохранения профиля/сессий и загрузки его кода/открытых настроек в приватный Actions artifact. Через 30 секунд после удаления повторно проверены схема, числа записей, профили и сессии источника, а также их наличие в основной D1 и здоровье основного Worker. Проверки прошли. Старая movement-test-app остаётся архивной D1 для восстановления и не обслуживает приложение. Данные D1 не удалялись. [Факты и артефакты выпуска](releases/2.5.4-2026-10-23.md).

Старые APK другого пакета, жёстко привязанные к выведенному адресу, больше не являются поддерживаемым приложением. Установленное Движение Тест UI продолжает использовать тот же основной URL и профиль.

## Дальнейшие выпуски

В Actions выбрать Movement — manual deployment, ветку main, ввести deploy. Выбора staging/production больше нет. BACKEND_TARGET отклоняется с объяснением, чтобы старые команды не направили выпуск в другую базу.

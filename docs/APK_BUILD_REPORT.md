## Исправления

- Обычная тренировка запрашивает камеру и считает без загруженного профиля.
  Такой подход явно обозначен как локальный тест без сохранения. Минуты и
  дуэли требуют профиля; серверный результат не имитируется.
- Адрес исправлен с `ais-pre` на предоставленный владельцем `ais-dev`.
  Добавлены изменение адреса в APK, проверка подключения и HTTP-код.
  HTML от предпросмотра / страницы входа распознаётся как неверный API-ответ.
- Добавлен Node-сервер для AI Studio / Cloud Run с тем же API и SQLite,
  миграциями, единым портом и Dockerfile. Sites сохраняет Worker и D1.
- Отказ камеры объясняет настройки разрешений Android; WebView без Web Locks
  может использовать единственную Activity. Для браузерных вкладок блокировка
  сохранена. Очередь и раунды изолированы по серверу.
- Сохранены воспроизводимая сборка, модель/WASM внутри APK, нативный HTTP,
  удержание экрана и исключение старых APK/исходных ZIP из нативных ресурсов.

## Что осталось вне среды сборки

APK не устанавливался нами на физический Samsung Galaxy S23. Разрешение
камеры и точность на реальных движениях нужно проверить на устройстве.
Доступ к Cloud Run из среды сборки ограничен сетевой политикой.
По сообщению владельца, опубликованный `/api/state` возвращает страницу,
поэтому текущий сервер требует обновления: APK сам этого не делает.

Google Cloud credentials в среде не настроены; облачный сервер и размещённый
Sites не публиковались. Перед тестом прогресса и дуэлей загрузите серверные
исправления в AI Studio и перезапустите / повторно опубликуйте приложение.
На Cloud Run локальный диск временный; для короткой сессии нужен один
экземпляр, для постоянной эксплуатации — устойчивое хранилище.

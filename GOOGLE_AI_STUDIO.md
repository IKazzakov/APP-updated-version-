# Разработка в Google AI Studio · 2.5.2

Google AI Studio остаётся редактором приложения. Исходники текущего этапа:
`rojoscarlos-cpu/Test`, ветка `codex/backend-hosting-2.5.1`.
Принятая 2.5.1 сохранена в `codex/build-android-apk`, коммит `5107454`.

Основной сервер: https://movement-test-api.rojoscarlos93.workers.dev.
Он работает независимо от предпросмотра AI Studio, на Cloudflare Workers + D1.

## Локальный / AI Studio предпросмотр

Нужен Node.js 24. Сохраните структуру проекта и package-lock.json.

```sh
npm ci
npm test
npm run dev
```

`npm run dev` запускает интерфейс Vite и Node API на одном порту.
Используется переменная `PORT` (по умолчанию 3000), адрес прослушивания
0.0.0.0. SQLite в `.data/` содержит только данные этого предпросмотра;
это отдельная база, не постоянная база Cloudflare.

Для прежнего Sites-предпросмотра оставлен `npm run dev:sites`.
Размещённый приватный APP и его данные текущим переносом не меняются.

## Правки и публикация

Сохраняйте изменения из AI Studio в GitHub в указанную ветку. Workflow
`.github/workflows/backend.yml` проверит код и обновит облачный сервер.
Результат и рабочий адрес видны в GitHub Actions. Подключение уже настроено
через repository secrets; значения не включаются в исходники.

`server/cloudflare.js` — облачный вход API; `server/device-auth.js` —
индивидуальные сессии; `server/api.js` — задания, раунды, дуэли и рейтинги.
Миграции `drizzle/0000`–`0003` не переписывайте: изменения схемы добавляйте
новым файлом. Инструкция: [docs/CLOUDFLARE_SETUP.md](docs/CLOUDFLARE_SETUP.md).

## Установленный APK

APK 2.5.2 содержит интерфейс, Pose Full и WASM локально. Он обращается к
Cloudflare API, а не к адресам ais-dev/ais-pre. Публикация сервера обновляет
серверную логику; изменения интерфейса установленного приложения требуют
новой сборки APK. Для сборки нужны JDK 21 и Android SDK 36: `npm run build:apk`.

Гостевой профиль принадлежит сессии устройства. Одинаковые имена не дают
доступ к одному аккаунту. Выход отзывает сессию; для сохранения профиля между
тестами оставляйте приложение авторизованным. Камера и счётчик без сервера
по-прежнему доступны как явно обозначенный локальный тест без сохранения.

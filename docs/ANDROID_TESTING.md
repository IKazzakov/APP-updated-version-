# Установка тестового APK на Samsung Galaxy S23

1. Скачайте `app-debug.apk` или получите его файлом через мессенджер.
2. Откройте файл на телефоне. Android может запросить разрешение установки
   из выбранного браузера или мессенджера.
3. Установите «Движение», запустите и выберите «Быстрый старт (Гость)»
   либо введите имя тестировщика.
4. При запуске тренировки разрешите доступ к камере. Микрофон не используется.
5. Для входа, сохранения прогресса, рейтингов и дуэлей нужен интернет
   и доступ к серверу приложения. Модель Pose Full и WASM включены в APK.

Это подписанная debug-сборка версии **2.5.0** для ручного тестирования,
не пакет для Google Play. Имя пакета — `com.movement.squat`, версия Android
— 20500, минимальная версия системы — Android 7.0 (API 24).

## Что проверить

- Телефон держит вертикальную ориентацию; камера включается и выключается.
- При хорошем освещении 10 полных приседаний дают прибавку 10.
- Дневной прогресс сохраняется после закрытия и повторного открытия.
- В минутном режиме работают подготовка, 5–4–3–2–1, сигналы и завершение.
- Другой тестировщик видит свой профиль; приглашение содержит адрес сервера,
  а не localhost, и открывает нужную дуэль.
- В диагностике есть фактические показатели модели. При ошибке отправьте
  отчёт вместе с ожидаемым и полученным числом повторений.

Сервер в этой сборке:
`https://ais-pre-unwfcvynbcdvpumsvvws2k-220077059769.europe-west2.run.app`.
Он сохранён из текущего проекта. Сборка APK не публикует и не запускает этот
сервер; для смены адреса требуется пересобрать с VITE_API_BASE_URL.

Установку и реальные движения на физическом S23 нужно проверять на устройстве.
Проверка подписи и содержимого APK не измеряет точность распознавания камеры.
Если Android сообщает о несовпадающей подписи с прежней debug-сборкой,
потребуется удалить прежнюю установку. При этом локальные неподтверждённые
повторения будут потеряны: сначала дождитесь синхронизации прогресса.

## Повторная сборка

Установите Node.js 24+, JDK 21 (с javac), Android SDK 36 и Build Tools 36.0.0.
Примите лицензии SDK и задайте JAVA_HOME и ANDROID_HOME:

```sh
npm ci
npm test
npm run build:apk
```

Подпись, версия, разрешения и комплектность ресурсов проверяются скриптом.
Результат: `work/artifacts/app-debug.apk` и `app-debug.apk.sha256`.
Версия Android вычисляется из package.json. Состояние Gradle и debug-ключ
хранятся в `work/`, не в Git. Для обновления поверх установленного APK
сохраняйте один debug-ключ между сборками.

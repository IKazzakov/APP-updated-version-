# Схема D1

Первоначальная SQL-миграция находится в `drizzle/0000_squat_mvp.sql`.
Это SQL-first схема: `drizzle/meta/_journal.json` задаёт порядок применения.
Приложение никогда не создаёт таблицы при обработке HTTP-запросов.
Уже применённые миграции неизменяемы; следующие изменения добавляются отдельными файлами.

`repetition_events` имеет уникальный ключ пользователя и события. Триггер в той
же SQLite-транзакции увеличивает дневной прогресс и создаёт награду с уникальным
ключом дня. Награда, повтор события и обновление счётчика не могут разойтись при
одновременных запросах. Частичный уникальный индекс запрещает две активные
минутные попытки одного пользователя, в том числе с разных устройств.
